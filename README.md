SkillMatchA decoupled full-stack web application designed to calculate exact match percentages between candidate skills and job requirements using a custom Set Theory algorithm.View Live Vercel Deployment | View Render API OverviewSkillMatch automates the resume screening process by mathematically evaluating a candidate's skill set against open job requisitions. The frontend provides a clean, responsive interface for data entry, while the backend API handles the heavy lifting, calculating match percentages and managing the persistent PostgreSQL database.
